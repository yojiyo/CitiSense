1.0 Application Introduction & Platform Overview

This manual guides you through the CitiSense Sentiment Analysis Dashboard, a proprietary tool for government agencies. CitiSense automatically converts large volumes of public feedback into actionable intelligence, helping administrators monitor and quantify public sentiment.

Methodology and Data Integrity

The system analyzes data from uploaded CSV files. Analysis uses a customized FastText model optimized for local dialects, categorizing comments as Positive, Neutral, or Negative. Access is strictly controlled via your Agency Code to ensure data security and segmentation.

Who Benefits

Policy Makers

Prioritize issues by identifying public frustration or satisfaction trends

Communications Teams

Craft precise, timely public response strategies based on sentiment data

Data Analysts

Centralize and segment large volumes of unstructured data quickly

2.2 Uploading Data for Analysis

This page is where you submit new comment files for immediate sentiment analysis.

Upload Process

  1. Preparation: Use the CSV Template Button to download the file with the required headers
  2. Upload: Drag or click inside the central box (File Input Area) to select a single CSV file
  3. Preview: Review the Preview of Uploaded File table to confirm data structure
  4. Process: Click Analyze Comments to start the analysis

Upload Pop-up Messages

Pop-up Message Description Action Required
Uploading File / Progress Bar Shows the percentage completion of the processing pipeline Wait for completion
Duplicate File Found Appears if the file name exists. Choose Keep Both (saves as a duplicate) or Replace (overwrites the original) Choose an option to proceed
Analysis Complete Processing is finished and data is ready for viewing Click OK to close and go to the Dashboard

Required CSV Format

Your CSV file must include these mandatory columns:

Column Header Description
agency_name Name of the government agency
comment_text The actual comment or feedback text
comment_timestamp Date and time when comment was made
post_topic Topic or category of the post
💡 Note

The system ignores extra columns that don't match the required template. Download the CSV template from the upload page for reference.

⚠️ Troubleshooting

If upload fails, confirm your CSV uses the exact template headers. The system accepts new uploads even if data contents match a previous file.

2.3 Dashboard Visualization and Management

A. Viewing and Filtering Data

  1. Sentiment Metric Cards: Review the count and trend comparison for Positive, Negative, and Neutral comments
  2. Sentiment Charts: Legend labels are clickable on all charts (Pie, Bar, Trend Over Time) to toggle visibility and isolate specific sentiment trends
  3. Top Representative Comments Section: Use the P/N/N filter buttons to view key comments by sentiment category
💡 Interactive Charts

Click on any legend label in the charts to show/hide that sentiment category. This helps you focus on specific trends.

B. Data Management (History Page)

  1. Access: Click the History Button in the sidebar
  2. View Details: Click any row in the table to instantly view a full details report for that dataset, including a table preview of the comments
  3. Control Visibility: Use the Hide/Show button to toggle the dataset's visibility on the main Dashboard
  4. Soft Delete: Use the Delete button to hide the file. Confirm the action in the Confirm Deletion pop-up
⚠️ Important: Soft Delete

The Delete button performs a Soft Delete. Data is hidden from all views but retained in the database for compliance and record-keeping.

💡 Tip: Zero Metrics?

If dashboard metrics show zeroes, check your Start Date and End Date filters. The date range must cover the period when your sentiment data was processed.

2.4 Exporting Reports

Report Generation Process

  1. Access: Click the Download Report button on the Dashboard
  2. Filter: Define the Agency, Start Date, and End Date
  3. Select Content: Use the Include Sections Checkboxes to select metrics, charts, and raw CSV Data. Add notes in the Notes/Descriptions textfield
  4. Generate: Click Generate Report. The button will display "Generating..." and become disabled
  5. Review: Click Preview to open the PDF visualization in a new tab for final review
  6. Download: Click Download PDF or Download CSV to save the final report locally

Export Options

📊 Sentiment Metrics

Include counts and trends for all sentiment categories

📈 Charts & Trends

Add visual representations (Pie, Bar, Trend Over Time)

☁️ Word Cloud

Include sentiment-based word cloud visualization

📄 Raw CSV Data

Export filtered comment data in spreadsheet format

⚠️ Important

Select at least one section under 'Include Sections' before generating the report. The buttons will remain disabled until content is selected.

💡 Custom Notes

Use the Notes/Descriptions field to add context, executive summaries, or recommendations that will appear in your PDF report.
